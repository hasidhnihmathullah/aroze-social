Aroze — Modern Social Media Platform
Developed for the CodeAlpha Full Stack Development Internship.

Aroze is a mobile-first social experience built with Django, SQLite, and vanilla JavaScript AJAX, featuring instant feed interactions, stories, dynamic user profiles, and administrative oversight.

Key Features
Discover Feed : Immersive visual cards with real-time AJAX like toggles and counters.
Stories Carousel: Dynamic creator discovery rail supporting one-tap follow/unfollow actions.
Comments Drawer: Slide-up bottom sheet allowing asynchronous comment posting without full page reloads.
Dedicated Profile View: User profile snapshot, follower/following metrics, and a 2-column masonry media grid.
Post Composer: Native-style composer supporting photo attachments with instant client-side preview.
Relational Backend: Django ORM structure managing Users, Profiles, Posts, Comments, and Follow relationships.

Tech Stack
Backend: Python, Django 6
Database: SQLite3
Frontend: HTML5, CSS3 (Custom Mobile Shell & Modern Design Tokens), JavaScript (Fetch API / AJAX)
